## 📖 课文简介

1928 年，朱德同志带领的红军在井冈山挑粮。已经四十多岁的朱德，和年轻战士一样，挑着沉重的粮食走五六十里山路。他的扁担上写着「朱德的扁担」五个字，表达了革命领袖与战士同甘共苦、以身作则的高尚品质。

## 🛠️ 使用说明

### 1. 课堂朗读

将 `*.mp3` 按数字顺序播放，配合同名 `*.png` 配图，可逐段讲解课文。

### 2. AI 绘图

打开 [`朱德的扁担`](./朱德的扁担) 文件，复制对应平台的提示词即可使用：

| 平台 | 推荐提示词 |
|------|-----------|
| Midjourney v6 | 英文提示词 + `--ar` / `--v` 参数 |
| Stable Diffusion XL | 中文提示词 + 负面提示词 |
| DALL·E 3 / 文心一格 | 直接用中文提示词 |
| Flux / 通义万相 | 中英文均可 |

### 3. 提示词避坑指南

- ❌ **不要**把 Markdown 表格 / 分隔线 / emoji 粘进提示词
- ✅ **要**把表格内容转化为连贯的自然语言
- ✅ **风格统一**：要么全写实，要么全绘本
- ✅ **身份明确**：写「朱德（中国革命领袖）」，不要「朱同志」
- ⚠️ 部分 API（如 AGNES）对政治人物 + 军事题材有**内容审核**，需匿名化处理，详见提示词文件中的说明
